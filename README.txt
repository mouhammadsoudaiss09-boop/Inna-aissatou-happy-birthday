INNA AISSATOU - BIRTHDAY SURPRISE WEBSITE

Included:
- index.html: the birthday page
- assets/: the three original photos supplied in the chat

IMPORTANT:
This package is not online yet, so a QR code cannot reliably open it from another phone until the folder is published on a hosting service.
The simplest route is to upload this folder to a static hosting service such as Netlify Drop or GitHub Pages, then test the published page on another phone. After you have the final public URL, use it to create the printable QR code.

Before printing:
1. Publish the website folder online.
2. Open the public URL on mobile data, not only Wi-Fi.
3. Test every photo and the page on another phone/browser.
4. Generate a QR code from the final public URL.
5. Print the QR code at least 3 cm wide with a white border and test the printed copy.

No photos have been AI-generated or face-altered in this package.
